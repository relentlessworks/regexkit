regexkit v0.1.0

Agentic-first regex testing and pattern matching service. Test patterns, extract matches, validate input, replace, and split text — all over plain HTTP, designed for AI agents.

Principles

  • The agent IS the interface — No UI, no SDK. The API is the product.
  • Plain text by default — One labeled, grepable line per record. JSON on demand via ?format=json or Accept: application/json.
  • Instructive errors — Every 4xx includes a hint telling the agent what to do next.
  • Self-documenting — GET /help returns a one-page operating manual.
  • Simple auth — OTP via email → long-lived bearer token.
  • Single static binary — Go + JSON file storage, zero external dependencies.
  • MCP connector — Speaks Model Context Protocol at /mcp.

Quick Start

# Build and run
make build && ./regexkit

# Or with Go
go run ./cmd/regexkit

Authentication

# 1. Request OTP
curl -X POST http://localhost:7700/auth/request \
  -d '{"email":"you@example.com"}' \
  -H 'Content-Type: application/json'
# status=otp_sent code=123456

# 2. Verify OTP → get token
curl -X POST http://localhost:7700/auth/verify \
  -d '{"email":"you@example.com","code":"123456"}' \
  -H 'Content-Type: application/json'
# token=abc123... workspace=ws_xxxxx

API Endpoints

Regex Operations

POST/test

Test a pattern against input, finding all matches.

curl -X POST http://localhost:7700/test \
  -H "Authorization: Bearer <token>" \
  -d 'pattern=\d+&input=hello123world456'
# matched=true count=2 match[0]=123 start=5 end=8 match[1]=456 start=14 end=17
POST/match

Find the first match with capture groups.

curl -X POST http://localhost:7700/match \
  -H "Authorization: Bearer <token>" \
  -d 'pattern=(\w+)@(\w+)\.(\w+)&input=user@example.com'
# matched=true full=user@example.com start=0 end=15 1=user 2=example 3=com
POST/replace

Replace all matches in input.

curl -X POST http://localhost:7700/replace \
  -H "Authorization: Bearer <token>" \
  -d 'pattern=\d+&input=hello123&replacement=NUM'
# result=helloNUM count=1
POST/split

Split input on pattern matches.

curl -X POST http://localhost:7700/split \
  -H "Authorization: Bearer <token>" \
  -d 'pattern=[,;]&input=a,b;c'
# count=3 [0]=a [1]=b [2]=c
POST/validate

Check if a pattern compiles.

curl -X POST http://localhost:7700/validate \
  -H "Authorization: Bearer <token>" \
  -d 'pattern=\d+\w+'
# valid=true

Pattern CRUD

POST/patterns

Save a named pattern for reuse.

curl -X POST http://localhost:7700/patterns \
  -H "Authorization: Bearer <token>" \
  -d '{"name":"email","pattern":"\\w+@\\w+\\.\\w+"}' \
  -H 'Content-Type: application/json'
# handle=pat_a1b2c name=email pattern=\w+@\w+\.\w+ flags=
GET/patterns

List all saved patterns.

GET/patterns/{handle}

Get a specific pattern by handle.

DELETE/patterns/{handle}

Delete a saved pattern.

MCP

POST/mcp

Model Context Protocol endpoint for chat client integrations. Supports initialize, tools/list, and tools/call methods.

Help

GET/help

Returns a one-page operating manual. Also available at /.well-known/agent.md.

Flags

FlagDescription
iCase-insensitive matching
mMultiline mode (^ and $ match line boundaries)
sDotall mode (. matches newline)

Response Format

Plain text by default — one labeled, grepable line per record. Add ?format=json or set Accept: application/json for JSON responses. Errors include a hint field for self-correction.
